# 1.4 render graph and buffer contracts

Canonical bodies: `shaders/program/*.vsh/fsh` (no version directive).
Entry points: root, `world-1` and `world1`, generated by `tools/sync_dimensions.py`.
Each entry adds one GLSL 120 version and one optional dimension define, then includes
its canonical body. Never hand-edit generated wrappers. CI and packaging check them.

## Order
1. Shadow map: opaque depth in shadowtex1; opaque+nearest translucent in shadowtex0;
   RGB glass transmittance in shadowcolor0, blending disabled. Closest layer only.
2. Opaque gbuffer: forward lighting + normal/roughness + material masks, RGB
   material F0, analytic motion and albedo. Unknown entity motion has invalid velocity.
3. deferred: AO and pre-translucent HDR copy. Sky-depth source texels use a
   reflection environment without point stars; direct scene color stays untouched.
4. deferred1–4: optional conservative minimum-depth reductions at half/quarter/
   eighth/sixteenth size. R32F values are positive view depth, sky is min(far,32000).
   Texel-center sampling is mandatory: interpolated min depths are NOT conservative.
5. deferred5: optional half-size SSGI / visible-emitter colored-light gather.
6. deferred6: optional half-size indirect history, depth rejection and neighborhood
   clipping. First two texels are reserved metadata, not displayable GI radiance.
7. deferred7: depth-aware upsample/add GI; update scene and opaque reflection copy.
   Preserve star-free background source texels instead of restoring visible sky stars.
8. Translucent forward geometry; composite water/refraction/SSR, caustics/foam/shafts.
9. composite1–2: optional reduced-size cloud layers then sky-aware full-size combine.
10. composite3: optional TAA; reflections are temporally filtered here with the scene.
11. composite4–5: reduced-size bloom, reusing cloud temporary storage after its last read.
12. final: camera effects, bloom, tone mapping, exposure, grading, dither/output.

## Color buffers (logical images, NOT driver allocation estimates)
| index | contents | format | dimensions |
|---|---|---|---|
| 0 | scene HDR | RGBA16F | full |
| 1 | encoded view normal, perceptual roughness | RGBA16F | full |
| 2 | metallic, interface kind (0/1/2), sky light, emission/history marker | RGBA16F | full |
| 3 | opaque HDR + positive view depth; alpha 0 invalid | RGBA16F | full |
| 4/5 | cloud temporary then bloom / bloom | RGBA16F | effect scale |
| 6 | TAA HDR history + view depth; metadata at texels (0,0)/(1,0) | RGBA16F | full |
| 7 | linear RGB F0 + AO (always, LabPBR or fallback) | RGBA8 | full |
| 8 | optional previousUV-currentUV, previous clip w, validity | RGBA16F | full |
| 9–12 | conservative minimum view depth | R32F | 1/2, 1/4, 1/8, 1/16 |
| 13 | indirect HDR history + signed depth; reserved metadata | RGBA16F | half |
| 14 | current indirect RGB + depth | RGBA16F | half |
| 15 | diffuse linear albedo + porosity | RGBA8 | full |

RENDERTARGETS uses indices up to 15; GLSL outputs occupy at most six draw slots.
This relies on modern Iris/OptiFine attachment remapping (intended Minecraft 1.21.4
contract), not a promise of running on ancient OpenGL 2 hardware despite GLSL 120.
Compiler reflection audits active sampler2D count against the GL 3.3 minimum of 16;
actual target attachment allocation/state still needs loader/GPU tests.

History alpha: positive view depth is reusable. Negative GI depth displays current
radiance but rejects next-frame reuse on unknown motion. Reserved history texels
store viewport split into base-16 high/low parts (exact for odd sizes through 32767), split frame counter (low modulo 1024 plus upper part) and negative dimension tag; upsample excludes them.
Glass/water have no complete previous geometry/optics: water history stays rejected.
Mob/bone transforms are NOT present; invalid vectors are deliberate, not fabricated.

## 1.4 source/precipitation contracts
Colortex3 alpha is sampled at snapped centers for validity/depth. Sky/hand alpha=0;
hand RGB=0, sky RGB=star-free environment. GI resolve preserves both invalid RGB
and depth. Do NOT restore alpha=1 or validate this snapshot against a later depth
layer. Rough SSR taps require positive, depth-compatible source alpha. Colortex2 G
is 0 opaque / 1 water / 2 glass; tests using >0.5 mean all unstable interfaces, but
water-specific optics must also test <1.5. Colortex7 RGB F0 is unconditional.
Weather draws ONLY color0 with alpha blending and rain.depth=false; no material,
normal, F0, albedo or velocity writes. Sheet clouds are analytic sky color, not a
new geometry/depth layer. Volume mode remains sky-only and uses existing passes.
