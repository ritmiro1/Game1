# Aetheris 1.4.0: проверка по утверждённому плану

Этот список НЕ помечен пройденным компиляцией. Нет локального запуска Minecraft.
Пользователь подтвердил работу предыдущих сборок с Iris и OptiFine; новой версии
нужно собственное сравнение. Не публиковать присланные личные скриншоты автоматически.

## Подготовка — одинаково для Iris и OptiFine
Записать версию загрузчика, GPU/драйвер, разрешение, FOV, дальность прорисовки,
яркость игры, ресурс-пак, профиль и TAA. Сбросить старые настройки, выбрать MEDIUM.
Для сравнения закрепить одну позицию/ракурс и время: /time set 1000 или 13000;
использовать /weather clear и /weather rain, дождаться плавного перехода погоды.
Сравнивать в одной точке после адаптации экспозиции, а не два случайных кадра.

| Сцена | Что проверять | Результат в игре |
|---|---|---|
| Железо/золото/медь/алмаз у воды, пустая рука и разные предметы | Нет наклеенного held-item; различаются цвет и ширина блика; LOW/linear/Hi-Z SSR | Не проверено |
| Стекло спереди/сзади, внутри и рядом с водой | Не попадает в водную оптику, нормаль верна с обратной стороны, нет неожиданного зеркала | Не проверено |
| Металл в дождь | Rain-проход не меняет нормали/материалы; нет внезапных бликов от капель | Не проверено |
| Фасад с факелом, ночь + дождь | Мягкий тёплый локальный свет, фактура стены, нет синего частокола | Не проверено |
| Тот же фасад, ясная ночь | Отличается покрытие/освещение неба, не только текстура осадков | Не проверено |
| Небо в сильный дождь, LOW/MEDIUM/HIGH/ULTRA | Нет ясного звёздного неба сквозь шторм; новые облака без ванильного дубля | Не проверено |
| Закрытый туннель и окно наружу | Нет погодной дымки в закрытой части; учесть ограничение sky-access proxy у тёмных окон | Не проверено |
| Туннель со стержнем/факелом | Сохраняется фактура, bloom не перекрывает стену; tint lightmap глобальный, не по типу лампы | Не проверено |
| Ночная вода, движение камеры 10 секунд | Нет точечных звёзд из fallback/SSR/GI; луна, берег и источники отражаются | Не проверено |
| День/закат, песок, мокрый камень и пористый материал | Нет сплошной засветки; мокрые материалы не становятся одинаково зеркальными | Не проверено |
| Nether/End + переходы | Нет дождевых эффектов Overworld и старой истории, нет shader/FBO errors | Не проверено |

## Диагностика отражений
Источник отражений содержит только текущую видимую непрозрачную сцену. Область,
закрытая рукой, исключена и заменяется fallback, а не восстанавливается из воздуха.
На силуэтах SSR может исчезать; это честное ограничение screen-space, не world tracing.

## Не объявлять выполненным
Идентификация цвета всех установленных ламп по vanilla lightmap, местные цветные
тени от каждой лампы, voxel GI и точная многослойная рефракция стекла не реализованы.
Погодная дымка — аналитическое приближение по освещённости неба, не 3D-симуляция.
