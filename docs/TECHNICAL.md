# Техническое описание и честный отчёт о технологиях

## 1. На чём сделано

| Слой | Технология |
| --- | --- |
| Графика | Three.js 0.170 (WebGL2), собственные шейдеры воды, неба и постобработки |
| Геометрия | процедурные генераторы (`lathe`, `tube`, `gridPlane`, `noisySphere`, `extrude`), 311 мешей + 32 инстанс-группы |
| Текстуры | процедурные (Canvas 2D → `DataTexture`): кора, камень, песок, дерево, металл, чешуя, карты нормалей и шероховатости |
| Постобработка | GTAO → UnrealBloom → Bokeh DOF → SMAA → OutputPass → цветокоррекция |
| Звук | WebAudio, полностью синтезированный (осцилляторы, шумовые буферы, фильтры) |
| Сборка | esbuild 0.24 → IIFE-бандл → один автономный `index.html` |
| Оболочка Windows | C (Win32 API) + WebView2, кросс-компиляция `zig cc` с Linux |

Никаких внешних ассетов: все текстуры, звуки и модели создаются кодом при запуске.

## 2. Производительность (замерено в прогоне)

* 311 мешей, 32 инстанс-группы, 62 уникальных материала, 48 программ шейдеров.
* 2 771 206 треугольников в кадре при пресете «ультра».
* Генерация мира при старте: ~313 мс (рельеф 200² + текстуры).
* `heightAt` — около 0.03 мс на запрос (используется физикой и водой).
* 90 кадров интеграционного прогона без единой ошибки GLSL.

## 3. Как проверялось без Windows и без браузера

Среда сборки — Linux без GPU, без Chromium и без Windows. Поэтому проверка
многоуровневая и честная:

1. **`tools/headless_test.mjs` — 61 проверка.** Топология и объёмы мешей (знаковая
   ориентация, `signedVolume`, флип граней), корректность GLSL (разбор через
   `@shaderfrog/glsl-parser`), совпадение высот волн на CPU и в шейдере, физика лодки,
   состояния рыбалки, квесты, достижения, DOM-идентификаторы, каталог идей.
2. **`tools/smoke_browser.mjs` — 47 проверок в jsdom + заглушка WebGL2.** Загружается
   реальный `dist/index.html`, три.js проходит весь путь: компиляция 48 программ
   шейдеров, создание 311 мешей, 90 кадров рендер-цикла, меню → новая игра → ходьба →
   лодка → рыбалка мышью → модальные окна → пресеты → погода → ночь → сейв → возврат в
   меню. Заглушка WebGL2 (`tools/mock_webgl.js`) отдаёт настоящие лимиты, расширения,
   FBO и принимает uniform-значения, проверяя их на конечность.
3. **`tools/verify_pe.mjs` — проверка `.exe`.** Разбирает PE-заголовки, дерево ресурсов
   и подтверждает: x86-64, подсистема Windows GUI, ресурс `RT_HTML/101` с игрой,
   байт-в-байт совпадение с `dist/index.html`, иконку и версию.
4. **`tools/test_httpd.mjs` — нативный тест мини-сервера.** Тот же `electron/httpd.c`,
   что внутри `.exe`, компилируется системным GCC под Linux и проверяется реальными
   HTTP-запросами: код 200/404, `Content-Length` в байтах, отдача настоящего файла игры
   (1 035 720 байт байт-в-байт), кириллица в UTF-8, автоперебор занятых портов,
   5 последовательных запросов. 23 проверки, прогоняется и внутри `tools/release.mjs`.

## 4. Что именно делает `.exe`

`TikhiyZaliv_v1.0.0.exe` — не «обёртка из архива» и не пустышка:

* нативное окно Win32 (класс `TikhiyZalivWindow`, минимальный размер 960×600, иконка,
  заголовок на русском);
* вся игра встроена в ресурс `RT_HTML/101` (около 1 МБ);
* при запуске поднимается локальный HTTP-сервер на `127.0.0.1` (порт 8765–8865),
  который отдаёт игру — поэтому у страницы настоящий origin и работают сохранения в
  `localStorage`, захват мыши и WebGL;
* копия игры пишется в `%LOCALAPPDATA%\TikhiyZaliv\app.html` как резервный путь
  (если порт занять не удалось, игра откроется по `file://`);
* рендерит всё системный WebView2 (движок Edge Chromium) — тот же движок, что в браузере.

## 5. Требования к системе

* Windows 10 (1809+) или Windows 11, 64 бита.
* Microsoft Edge WebView2 Runtime — в Windows 11 и большинстве сборок Windows 10 уже
  установлен; если нет, игра покажет сообщение со ссылкой на установщик.
* Видеокарта с WebGL2 (любая дискретная или встроенная после 2015 года), 4 ГБ ОЗУ.

## 6. Ограничения и честные оговорки

* **`.exe` собран кросс-компилятором `zig cc`, а не MSVC.** Это настоящий PE-файл
  x86-64 с нативным оконным кодом, но он **не подписан** — Windows SmartScreen может
  показать предупреждение «Неизвестный издатель».
* **Запуск на Windows не проверялся в этой среде** (здесь Linux без Wine). Проверены
  PE-структура, ресурсы и корректность ABI WebView2 по официальному `WebView2.idl`;
  логика игры проверена в jsdom.
* Кадры рендерились через заглушку WebGL2, а не на реальном GPU, поэтому скриншотов
  из игры нет: визуальная проверка — это просмотр шейдеров, геометрии и снимков
  отдельных процедурных текстур.
* Нет мультиплеера, озвучки и мобильного управления.
* Каталог идей (`100_3D_GAME_IDEAS.md`, 100 позиций) — это дизайн-документ, а не
  обещание реализовать все сто игр.

## 7. Команды разработчика

```bash
node build.mjs                  # сборка dist/game.js + автономный dist/index.html
node serve.mjs                  # http://localhost:8080
node tools/headless_test.mjs    # 61 проверка без браузера
node tools/smoke_browser.mjs    # 47 проверок в jsdom + заглушка WebGL2
node tools/test_httpd.mjs       # 23 проверки HTTP-сервера, который работает в .exe
node tools/release.mjs          # .exe + ZIP в release/
```

Требуется Node 20+. Для сборки `.exe`: `pip install ziglang` (даёт `zig` 0.17) —
кросс-компилятор Windows на Linux без дополнительных пакетов.
