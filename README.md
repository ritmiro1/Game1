## 🎮 Геймплей — за 60 секунд

**Поле 7×7** • 3 твоих резонатора (бирюза) vs 3 врага (малина) • В центре **Ядро Резонанса** • Порталы на базах (центр верхней/нижней линии) • 4 аномалии (непроходимы)

**Цель — 2 пути:**
1. **Заведи Ядро в портал врага** — используй способности: **ТЯГОТЕНИЕ** тянет Ядро к тебе, **РЕЗОНАНС** толкает от тебя, **ИМПУЛЬС** меняет тебя с Ядром местами (кд 2). Стоят 2⚡.
2. **Захвати всех врагов** — встань на их клетку (ход как король: 1 клетка в любом направлении, 0⚡)

**Сердце — одновременность:**
- Каждый ход +1⚡ (макс 5). Вы оба выбираете действие **скрытно**, затем reveal. 
- Пошли в одну клетку? **Столкновение** — оба оглушены на ход.
- Оба толкаете Ядро? Векторы складываются или гасятся.
- **Пас** — сильнейший блеф: экономишь ⚡ и ловишь врага на предсказании.

**Победа:** доставка Ядра, аннигиляция или тай-брейк на 40-м ходу. Ничья — стабилизация резонанса.

## 🛠 Установка (разработчикам)

```bash
git clone https://github.com/ritmiro1/Game1.git
cd Game1
npm install
npm start          # http://localhost:3000 — игра + сервер арены
# или только статика
npx serve .        # http://localhost:3000
```

**Структура:**
```
index.html          # SPA, 5 экранов + оверлей дуэли
css/style.css       # ~1000 строк, неон-футуризм, адаптив
js/core/board.js    # правила, синхронный резолв, оценка
js/ai/search.js     # Maximin, AlphaBeta, 12k узлов
js/ai/personalities.js # 5 ботов
js/ui/boardRenderer.js # Canvas 560×560, анимация, частицы
server/server.js    # Express + ws, лобби, чат
electron/main.js    # десктоп-обёртка
dist/*.exe          # Windows инсталлер
```

**Сборка EXE:**
- Локально: `npm run build:exe` (требует wine для win-x64) или используй GitHub Actions
- CI: `.github/workflows/build.yml` — собирает win-x64, mac, linux на каждый релиз
