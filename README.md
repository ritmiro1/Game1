# Тихий Залив — 3D-симулятор рыбалки и исследований

**Версия 1.0.0** · процедурный архипелаг · Three.js + WebGL2 · интерфейс полностью на русском

«Тихий Залив» — атмосферная 3D-игра о тихой воде, маяке и рыбе, которую не терпится
поймать. Мир не нарисован вручную: рельеф, берега, лес, камни, маяк, хижина, причал,
лодка и двенадцать видов рыб генерируются кодом при каждом запуске (с фиксированным
зерном — мир узнаваем).

---

## Как запустить

### Вариант 1. Готовый `.exe` (Windows 10/11)

1. Запустите `TikhiyZaliv_v1.0.0.exe`.
2. Игра откроется в собственном окне (нативный Win32 + системный WebView2).

Внутри `.exe` лежит вся игра целиком (HTML + CSS + JS, ~1 МБ). При старте она
распаковывается в `%LOCALAPPDATA%\TikhiyZaliv\app.html` и раздаётся локальным
сервером на `127.0.0.1` (свободный порт 8765–8865), поэтому работают сохранения в
`localStorage`, захват мыши и WebGL. Интернет не нужен.

Нужен установленный компонент **Microsoft Edge WebView2 Runtime** — в Windows 11 и в
большинстве сборок Windows 10 он уже есть. Если его нет, игра покажет сообщение с
ссылкой на установщик.

### Вариант 2. Браузер

Откройте `dist/index.html` — это тот же самый автономный файл (1 МБ, ничего не
подгружает из сети). Либо раздайте папку `dist` любым статическим сервером
(`node serve.mjs` → http://localhost:8080).

## Управление

| Клавиши | Действие |
| --- | --- |
| `W A S D` | идти |
| `Shift` | бежать |
| `Space` | прыжок |
| `C` | присесть |
| `V` | вид от первого / третьего лица |
| `F` | достать / убрать удочку |
| `ЛКМ` | заброс (отпустить), подсечка, вываживание |
| `ЛКМ` 0.6 с | смотать снасть |
| `E` | взаимодействие (лодка, костёр, верстак, записки) |
| `Tab` | инвентарь и наживка |
| `J` | журнал рыб и квесты |
| `Esc` | пауза |
| колесо | сменить наживку |

Рыбалка: `F` → зажать ЛКМ (сила заброса растёт «маятником») → отпустить → дождаться
поклёвки (`ПОКЛЁВКА!`) → ЛКМ — подсечка → удерживать ЛКМ, пока не кончится сила рыбы.
Слишком сильное натяжение рвёт леску.

## Что внутри

**Мир.** Процедурный рельеф 600×600 м с биомами (сосновый бор, каменистый берег,
камышовая отмель, четыре острова), трава, камыш, папоротники, цветы, поваленные
стволы, валуны — всё настоящими мешами и инстансами (≈2.77 млн треугольников в кадре).

**Вода.** Шесть волн Герстнера в вершинном шейдере, две прокручивающиеся карты
нормалей, глубина из карты высот, каустика, пена у берега и на гребнях, подповерхностное
рассеяние, блик Кука–Торранса, лунная дорожка, планарное отражение и преломление сцены.

**Свет и атмосфера.** Полный цикл суток (свой небесный шейдер, звёзды, луна), пять
погод (ясно, облачно, дождь, туман, шторм), volumetric-god rays, тени с PCF-soft,
GTAO, UnrealBloom, боке-глубина резкости, SMAA, цветокоррекция и зерно.

**Живое.** Скелетные и пружинные анимации: деревья качаются на ветру, рыба бьётся на
леске, лодка качается на волнах (buoyancy по высоте волны), чайки, дым костра, искры,
брызги, круги на воде.

**Игра.** 12 видов рыб с редкостью, весом, ценой и временем клева; 8 наживок;
6 квестов; 14 достижений; день/ночь и погода влияют на клёв; экономика (продажа улова,
покупка наживки в инвентаре); сохранение в JSON (`localStorage`) с автосейвом.

## Сборка из исходников

```bash
npm install            # three, esbuild, jsdom, @napi-rs/canvas
node build.mjs         # dist/game.js + автономный dist/index.html
node serve.mjs         # локальный сервер на :8080
node tools/headless_test.mjs    # 61 проверка без браузера
node tools/smoke_browser.mjs    # интеграционный прогон в jsdom + заглушка WebGL2
node tools/release.mjs          # релиз: .exe и .zip → release/
```

`tools/release.mjs` собирает Windows-исполняемый файл кросс-компилятором
`zig cc -target x86_64-windows-gnu` (Zig ставится из PyPI: `pip install ziglang`),
проверяет готовый PE (`tools/verify_pe.mjs`) и упаковывает исходники в ZIP.

## Структура

```
src/core/      движок: рендер-пайплайн, атмосфера, вода, материалы, звук, математика
src/gen/       процедурная генерация: геометрия, текстуры, рельеф
src/models/    модели: природа, постройки, рыбы
src/game/      игра: мир, игрок, лодка, рыбалка, квесты, интерфейс, частицы
src/data/      каталог 100 идей (встраивается в бандл)
electron/      нативный лаунчер Windows (C + Win32 + WebView2) и иконка
tools/         тесты, заглушка WebGL2, генератор идей, упаковка релиза
dist/          собранная игра (game.js + автономный index.html)
```
